# Frontend do FIEC Taskcall

O frontend final e integrado ao Laravel fica em `src/backend/resources/js/taskcall` e deve ser executado pelo Vite do diretório `src/backend`.

Não use esta pasta para iniciar o sistema final. Para iniciar tudo, execute `iniciar-taskcall.bat` na raiz do projeto ou, manualmente, use `src/backend`: `npm install` e `npm run dev`, além de `php artisan serve --port=8000`.

A pasta `src/frontend` é mantida apenas para preservar os arquivos originais do projeto.
